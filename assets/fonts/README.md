# 字体

- `Chinese.ttf`：Noto Sans SC，固定字重 400。来源：[Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc)。许可：[SIL OFL 1.1](NotoSansSC-OFL.txt)。
- `Display.ttf`：Inter，固定字重 700、optical size 14。来源：[Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter)。许可：[SIL OFL 1.1](Inter-OFL.txt)。

由官方可变 TTF 使用 FontTools `instantiateVariableFont` 生成静态实例，保留内部版权信息。项目保留原运行时文件名，便于所有界面共用这些字体。
